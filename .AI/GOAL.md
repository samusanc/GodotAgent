# Session Goal

The goal of this session is to create the standard Godot development folder structure inside the `project/` directory.

## Standard Folders to Create:
- `project/systems/` (for reusable, project-agnostic components)
- `project/autoload/` (for global managers)
- `project/resources/` (for custom resource types and scripts)
- `project/shared/` (for cross-feature assets like audio and sprites)

These match the layout rules defined in `GEMINI.md` and `godot-architecture.md`.

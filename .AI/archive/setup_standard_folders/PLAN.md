# Technical Plan - Standard Godot Folders

We need to create the standard folder structure inside the `project/` directory of our workspace.

## Directory Tree to Create
We will create the following directories under `project/`:
- `project/systems/`
- `project/autoload/`
- `project/resources/`
- `project/shared/`

## Implementation Steps
1. Create each folder under `project/`.
2. Place a `.gitkeep` file in each folder so they are tracked by Git even when empty.
3. Check the git status and check that the folder layout is correct.

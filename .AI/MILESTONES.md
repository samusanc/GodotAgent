# Milestones - Standard Godot Folders

Each milestone must keep the project in a working state.

## Milestone 1: Create Folder Structure and .gitkeep files
- Create directories:
  - `project/systems/`
  - `project/autoload/`
  - `project/resources/`
  - `project/shared/`
- Add a `.gitkeep` file in each directory.

## Milestone 2: Verification
- Verify that the directories exist and are correctly tracked by git.
- Verify using `git status`.
